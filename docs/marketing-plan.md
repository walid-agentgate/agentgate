# AgentGate Marketing Plan — After Design Partner Readiness

## Phase 1 — Evidence
Secure 3–5 design partners and publish only partner-approved results.

## Phase 2 — Positioning
Use one category statement:

> AgentGate is the runtime control plane for AI agent actions.

Core promise:

> Stop dangerous agent actions before they execute — and prove what happened.

## Phase 3 — Content
1. Technical demo: refund agent.
2. Attack Lab demonstration.
3. Shadow → Enforce walkthrough.
4. Replay evidence walkthrough.
5. Partner case study when approved.

## Phase 4 — Distribution
- GitHub / npm developer funnel.
- Founder-led technical outreach.
- AI engineering/security communities.
- Short technical videos demonstrating real decisions.
- Documentation and integration examples.

## Phase 5 — Conversion funnel
Content → Quickstart → protected tool → Attack Lab → Shadow → Design Partner → Production → Paid plan.

## Claims policy
Prefer measured statements. Avoid absolute claims such as “makes agents safe,” “prevents all prompt injection,” or “replaces IAM/SIEM.”
